# RepositorioPrueba1

Repositorio de ejemplo del módulo **Despliegue de Aplicaciones Web** (DAW2, IES Los Olivos).

Se usa en la UT6 para practicar con Git y GitHub: clonar, explorar el historial
y ver cómo quedan los Pull Requests una vez aceptados.

## Cómo contribuir

1. Haz un fork de este repositorio.
2. Crea una rama para tu cambio: `git switch -c tipo/descripcion`.
3. Haz tus commits y sube la rama a tu fork.
4. Abre un Pull Request hacia la rama `main` de este repositorio.
